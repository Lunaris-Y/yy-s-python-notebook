# 01 Python 简介

## 本节目标

- 了解 Python 是什么
- 认识 Python 程序的基本形式
- 学会运行第一段 Python 代码

## 什么是 Python

Python 是一种语法清晰、容易入门的编程语言。它可以用于自动化、数据分析、人工智能、网站开发等领域。

Python 程序通常保存在扩展名为 `.py` 的文件中，例如：

```text
hello.py
```

## 第一段 Python 代码

```python
print("Hello, Python!")
```

`print()` 的作用是把括号中的内容输出到屏幕上。字符串需要放在英文单引号或双引号中。

运行结果：

```text
Hello, Python!
```

## 添加注释

注释是写给程序阅读者看的说明，不会被 Python 执行。单行注释以 `#` 开头：

```python
# 输出一条欢迎信息
print("欢迎学习 Python！")
```

## 简单练习

尝试修改下面的内容，让程序输出你的姓名和学习目标：

```python
print("你好，我是小明")
print("我的目标是学会使用 Python 编程")
```

## 易错点

- `print` 应使用英文小写字母
- 括号和引号应成对出现
- 中文标点不能代替代码中的英文括号和引号
- Python 对字母大小写敏感，`Print` 和 `print` 不相同

## 本节总结

Python 是一门应用广泛且适合初学者的编程语言。我们可以使用 `print()` 输出内容，并使用 `#` 添加单行注释。
